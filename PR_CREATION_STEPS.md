# Steps to Create a Pull Request on GitHub

1. Go to the GitHub repository: [https://github.com/ramalingam123maha-commits/Student_Management](https://github.com/ramalingam123maha-commits/Student_Management)

2. Click on the "Pull requests" tab

3. Click on the "New pull request" button

4. Set the base branch to `main` and the compare branch to `agent/e7e2e167-23cb-41a7-87f7-51274ce518d3`

5. Click "Create pull request"

6. In the pull request form:
   - Title: "Fix: Add Login Page for Student Management System"
   - Copy and paste the content from the PR_TEMPLATE.md file in this directory

7. Click "Create pull request" to submit

## Pull Request Content
The content for your pull request has been created in the PR_TEMPLATE.md file. You can open this file to copy its contents when creating the PR.
