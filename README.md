# SyncSpace - Collaborative Task Manager

A full-stack collaborative Task Management application designed for agile teams.

## Key Features
- **Task Creation & Assignment:** Create rich tasks with titles, descriptions, due dates, multi-tag categorization, and assign directly to team members.
- **Priority Levels:** Organize work into Urgent, High, Medium, and Low priorities with custom color tokens and filter pills.
- **Interactive Kanban Board & List Views:** Drag/select status pipelines (To Do, In Progress, Review, Completed) with live counter ribbons and tabular overview.
- **Collaborative Comments & Discussion:** Real-time team commentary thread per task to discuss specs and reviews.
- **Audit & Activity Tracking:** Automatic logging of assignment reassignments, status transitions, priority shifts, and member comments.
- **Team Workload Matrix:** Visibility into individual workload allocation across team members to prevent burnout.

## Verification
Automated test suite (`npm test`) validates user directory, task creation, patch updates, activity auditing, and collaborative comment posting.
